The control is a boundary, not a promise.

This model assumes an external authorization layer can reject actions unrelated to the user's task. It does not assume that an instruction telling an LLM to ignore malicious text is sufficient.

Capability restrictions independently deny the simulated sensitive action. The approval gate pauses the action; it does not automatically approve or guarantee a good reviewer decision. Audit logging records events but does not block execution.

Background: OWASP AI Agent Security Cheat Sheet and Prompt Injection Prevention Cheat Sheet. Scenario outcomes here are authored rules, not empirical attack-success rates.
