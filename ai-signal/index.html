01 / AgentsReported signal

The API fallback started speaking.

Google says Gemini-powered Duplex can use the telephone when an online API or booking form does not exist. The signal is not proven reliability. It is a broader action surface: an agent can now cross a human-operated legacy interface without the business building an integration.

02 / AgentsReported signal

The incident queue became a workflow.

OpenAI's Performance Factory turns a production alert into persistent agent work: investigate, record evidence, challenge the diagnosis, propose a fix for engineer review, wait for deployment, and verify recovery. The signal is not autonomous SRE. It is a stateful operating workflow in which scoped identity, durable task state, adversarial review, human merge authority, and post-deployment evidence surround the model.

Stateful, reviewed production-agent workflows19 Nov 20264 min read
Important
03 / InfrastructureReported signal

The deprecation notice found the repository.

AWS Transform can now connect planned cloud lifecycle events—such as an expiring Lambda runtime or EKS version—to affected repositories, grouped findings, a proposed transformation, and one reviewable pull request per repository. The signal is not autonomous modernization. It is that provider lifecycle evidence is becoming supervised, portfolio-scale maintenance work.

Portfolio-scale supervised maintenance automation19 Nov 20264 min read
Important
04 / Enterprise AIReported signal

The agent got an employee badge.

AWS, Microsoft, GitHub, and now Google Cloud are moving agents into the identity lifecycle used for people and workloads. Google's Unified Access Policies add first-class agent principals, pools, allow and deny rules, and short-lived downscoped tokens—useful cross-vendor evidence, still bounded by preview status and unresolved documentation limits.
