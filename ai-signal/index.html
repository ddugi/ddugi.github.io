02 / ModelsReported signal

The legacy-language gap narrowed.

OpenAI reports large gains on two new coding evaluations covering 20 programming languages and behavior-preserving COBOL migration. The strongest result is not that a model can translate old syntax. It is that models are being tested against observable behavior in languages that run essential systems—while production correctness, independent replication, and benchmark breadth remain open.

03 / Security & GovernanceReported signal

The license policy entered the merge gate.

GitHub made enterprise-wide open-source license checks generally available as a ruleset condition. A dependency can now be checked before merge—and through an API before a coding agent recommends it. The useful shift is from after-the-fact inventory to a reviewable policy boundary, with exceptions and human ownership still visible.

Machine-readable open-source license policy in repository workflows16 Oct 20264 min read

04 / Security & GovernanceReported signal

The pentest agent found the bug—and broke the target.

AWS tested an autonomous security agent against 37 recent, live vulnerability targets. An audit credited 33 intended end-to-end exploits, but two apparent wins came through benchmark flaws and two other runs crashed the target before retrieving proof. The useful signal is capability under audit—and the operational gap between finding a vulnerability and testing it safely.

Autonomous penetration testing against recent real-world vulnerabilities15 Oct 20264 min read

05 / Security & GovernanceReported signal

The security agent entered the pull request.

GitHub made AI Scan for pull requests and agentic autofix for code-scanning alerts generally available. Detection, explanation, repair, and validation are moving into the repository workflow—but the AI finding is advisory, the repair opens a draft, and neither release turns model output into a security verdict.
