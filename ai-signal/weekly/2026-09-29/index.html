Weekly Signal / 29 Sep 2026 / published

The model race is becoming an efficiency race

This edition updates the frontier-model signal after Anthropic pushed its efficiency story into the everyday Sonnet tier and GitHub distributed that model through Copilot.

The connecting thread

Capability still matters, but the enterprise decision increasingly depends on accepted work per unit of time, tool use, policy, and spend.

  1. Enterprise AI / Structural Shift

    The office assistant is becoming a managed workload.

    Microsoft put persistent agents, generated apps, tenant hosting, identity, governance, and usage billing into one Copilot product story. The new unit of work needs an operator, not just a prompt.

  2. Security & Governance / Important

    The AI control plane now decides what arrives by default.

    GitHub added local boundaries for agent-run commands and a global default for future Copilot features. Enterprise AI policy is moving from scattered toggles into a control plane.

  3. Models / Important

    The model race is becoming an efficiency race.

    Anthropic extended its 5.5 efficiency push from Opus to Sonnet, while GitHub placed the new model directly into Copilot. The useful contest is moving toward accepted work per unit of cost and time.

  4. Security & Governance / Important

    An advisory group can review the result. It cannot control the race.

    OpenAI and nine mathematicians established an independent group to advise on mathematical AI results. Its remit is public; its power is limited.

  5. Research / Important

    RetroChimera makes chemist judgement part of the test.

    A new retrosynthesis system combines two different model types and asks expert chemists whether the proposed routes make sense. That is better evidence, with a small but important caveat.

What we would watch next

Questions for future reporting, not predictions or current claims.

  • Independent cost-per-accepted-task measurements for Sonnet 5.5 across representative enterprise workloads.
  • Whether fewer steps and tool calls persist outside Anthropic and GitHub selected evaluations.
  • How GitHub enterprise model policies affect rollout consistency, cost, and auditability.
  • Production evidence for Copilot Managed Runtime isolation, recovery, inventory accuracy, and tenant policy enforcement.
  • Independent laboratory validation of RetroChimera routes beyond expert preference tests.

The cheapest token is not necessarily the cheapest result. The next useful benchmark is the bill for work someone accepts.
