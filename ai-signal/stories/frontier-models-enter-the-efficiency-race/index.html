The model race is becoming an efficiency race.

Anthropic extended its 5.5 efficiency push from Opus to Sonnet, while GitHub placed the new model directly into Copilot. The useful contest is moving toward accepted work per unit of cost and time.

01 / Evidence boundary

Verified facts

  • Anthropic released Claude Opus 5.5 on 22 September 2026. [anthropic-opus-55]
  • Anthropic lists Opus 5.5 at $4 per million input tokens, $20 per million output tokens, and $0.20 per million cache-read tokens, compared with $5, $25, and $0.50 for Opus 5. [anthropic-opus-55]
  • Anthropic reports that Opus 5.5 costs 40% less than Opus 5 on its typical-workload tests and generates output more than 30% faster. [anthropic-opus-55]
  • Anthropic says Frontier Design and METR evaluated the model before release and that biology and cybersecurity safeguards route some work through restricted access or another model. [anthropic-opus-55] [anthropic-opus-55-system-card]
  • Anthropic states that Opus 5.5 may recognize evaluation settings and that pre-deployment evaluations cannot reliably catch every failure. [anthropic-opus-55-system-card]
  • Anthropic released Claude Sonnet 5.5 on 28 September 2026 and says it generates output more than 30% faster than Sonnet 5. [anthropic-sonnet-55]
  • Anthropic lists Sonnet 5.5 at the same token prices as Sonnet 5—$2 per million input tokens, $10 per million output tokens, and $0.20 per million cache-read tokens—and reports up to 30% lower cost per task because it typically uses fewer tokens. [anthropic-sonnet-55]
  • Anthropic says Sonnet 5.5 is available through its platform and on Amazon Web Services, Google Cloud, and Microsoft Azure. [anthropic-sonnet-55]
  • GitHub announced Claude Sonnet 5.5 as generally available in GitHub Copilot on 28 September 2026, with a gradual rollout across its listed editors, agents, apps, web, CLI, and mobile clients. [github-sonnet-55-copilot]
  • GitHub says Business and Enterprise administrators can manage Sonnet 5.5 through the Copilot model policy, and that new models are enabled by default unless the administrator disables the global default or the model. [github-sonnet-55-copilot]
Reporting context

Anthropic released Claude Sonnet 5.5 with unchanged per-token pricing but provider-reported reductions in tokens, task cost, and completion time; GitHub made it generally available in Copilot.

02 / Observed change

What actually changed

Anthropic extended its efficiency claim from the premium Opus tier to the everyday Sonnet tier. Sonnet 5.5 keeps Sonnet 5 token prices, but Anthropic reports fewer tokens per task, lower task cost, and faster output. GitHub then made the model generally available across Copilot clients with enterprise model-policy controls.

03 / Interpretation

Why it matters

The practical model decision is no longer only which system tops a benchmark. Teams increasingly need to know which model finishes an accepted task with the least waiting, tool use, correction, and spend. Putting Sonnet 5.5 into Copilot makes that trade-off available inside existing developer workflows rather than as a separate experiment.

04 / Engineering analysis

Technical implications

Evaluate complete tasks at fixed effort settings and record success, retries, tokens, tool calls, latency, safeguard fallbacks, and human correction. Treat model availability as a governed dependency: GitHub administrators can control access, and a gradual rollout means the same organization may temporarily see different options.

05 / Potential beneficiaries & pressure

Business implications

A faster general-purpose model at unchanged token prices can still reduce the effective cost of high-volume work if it reliably uses fewer tokens and steps. Procurement should test representative tasks before changing routing or budgets, because the strongest efficiency evidence remains provider-reported.

06 / Possibility, not certainty

Where this could be going

Conditional outlook · Not a fact

Conditional outlook: if independent workload tests confirm lower cost per accepted task, model competition may shift from premium benchmark peaks toward efficient routing between capable tiers. If gains depend on Anthropic-selected evaluations, effort settings, or favorable tool patterns, the operational advantage will be narrower than the launch suggests.

07 / What could change the picture

Risks & uncertainties

  • Anthropic reports the speed, token-use, task-cost, benchmark, and alignment comparisons; they are not independent measurements across customer workloads.
  • Sonnet 5.5 keeps Sonnet 5 per-token prices. The claimed cost reduction depends on using fewer tokens and steps, which may vary by prompt, tools, effort setting, and acceptance criteria.
  • Anthropic says benchmark scores capture only one part of capability and that Opus 5.5 remains stronger for complex, open-ended work requiring sustained judgment.
  • GitHub describes a gradual rollout, so general availability does not mean every eligible user receives the model at the same moment.
  • Default model enablement can broaden access unless administrators disable the global default or the model, making rollout policy part of the cost and risk decision.
  • Anthropic says no evaluation set catches every failure and applies cybersecurity fallbacks to some higher-risk requests; effective behavior can therefore differ by task category.
08 / Editorial analysis

The AI Signal take

The quiet shift is from buying tokens to buying completed work. Sonnet 5.5 keeps the old token price, yet Anthropic argues that fewer steps make each task cheaper. GitHub distribution turns that claim into an immediate enterprise routing question—but the receipt still needs independent measurement.
