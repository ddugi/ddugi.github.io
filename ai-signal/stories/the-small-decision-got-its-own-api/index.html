Agents / Typed low-latency decisions inside agent workflowsImportantReported signal

The small decision got its own API.

OpenAI made a dedicated endpoint generally available for bounded choices, probabilities, and rubric scores. The useful shift is architectural: agents can route, classify, or escalate through a typed low-latency step instead of asking a full generative model every time—while calibration, threshold design, hot-path failure, and vendor-only performance evidence remain the real work.

01 / Evidence boundary

Verified facts

  • OpenAI made the Decisions API generally available on 22 October 2026 through the dedicated /v1/decisions endpoint, currently using GPT-6 Luna. [openai-decisions-ga] [openai-api-changelog]
  • The endpoint accepts shared text, image, or structured JSON evidence and supports between one and 400 questions in a request; the public beta limit was 200. [openai-decisions-ga] [openai-api-changelog]
  • The API supports three bounded answer types: predicate returns a probability, choice selects from supplied values and includes probabilities and confidence, and score returns a probability-weighted result across ordered levels. [openai-decisions-ga]
  • OpenAI reports that Decisions can return typed answers up to ten times faster than GPT-6 Luna through the Responses API; the announcement does not publish a complete independent benchmark or latency distribution for that headline figure. [openai-decisions-ga]
  • The generally available release adds prompt caching, native JSON input, images in question instructions, organization usage reporting, Private Link, and native GPT-Live integration. [openai-api-changelog]
  • OpenAI lists the Decisions endpoint at $0.10 per million input tokens with no output-token charge, while noting that regional processing premiums and long-context multipliers can apply. [openai-decisions-ga]
  • OpenAI says the endpoint supports regional processing in the United States and Europe and is eligible for Zero Data Retention for qualifying customers. [openai-decisions-ga]
  • OpenAI’s announcement includes customer-reported examples from Box, Datadog, Ramp, Sierra, and Speak, but provides no shared test set or independently reproduced comparison across those workloads. [openai-decisions-ga]
Reporting context

OpenAI separated recurring bounded decisions—continue, retry, route, score, or escalate—from open-ended generation and exposed them through a dedicated GPT-6 Luna endpoint with typed answers.

02 / Observed change

What actually changed

A common agent operation became a separate inference primitive. Applications can send evidence plus an explicit question contract and receive a probability, fixed choice, or rubric score, rather than generating prose and parsing it back into control flow. That creates a narrower interface for the frequent decisions between larger reasoning steps.

03 / Interpretation

Why it matters

Agents spend much of their time making small choices: whether to continue, which queue should receive a request, whether a command looks risky, or when a human should review. Using a full generative response for each choice adds latency, cost, and output ambiguity. A typed endpoint can make those transitions cheaper to inspect and easier to test, but it also puts probabilistic model output directly in the path of real actions.

04 / Engineering analysis

Technical implications

Define each decision around observable evidence and explicit allowed outcomes. Build a labeled evaluation set, measure calibration as well as accuracy, choose thresholds from the cost of both error types, and route uncertain or high-impact cases to deterministic checks or human review. Log the evidence, answer, confidence, threshold, model version, and resulting action. Add timeouts and a safe fallback because a fast decision service in the hot path is still a dependency.

05 / Potential beneficiaries & pressure

Business implications

A dedicated low-cost decision layer can make high-volume classification, routing, and agent orchestration economically practical and more responsive. The saving is credible only when teams include evaluation, monitoring, review queues, failure handling, and the cost of wrong actions. A cheap inference call can create an expensive operational error if its threshold is poorly chosen.

06 / Possibility, not certainty

Where this could be going

Conditional outlook · Not a fact

Conditional outlook: if independent evaluations show stable calibration and useful latency across real workloads, bounded decision endpoints could become a standard layer between agent reasoning and action. If teams treat confidence as correctness, skip workload-specific tests, or place the endpoint in irreversible flows without a safe fallback, faster decisions will mainly make mistakes happen sooner.

07 / What could change the picture

Risks & uncertainties

  • The up-to-ten-times speed claim comes from OpenAI and is not accompanied by a public cross-workload benchmark, full latency distribution, or independent reproduction.
  • Customer examples use different baselines and private workloads, so their speed, cost, and accuracy claims are not directly comparable.
  • Only GPT-6 Luna is supported, creating model and provider concentration for applications that adopt the endpoint contract.
  • A probability or confidence value is not automatically calibrated for a team’s data, risk tolerance, or changing production distribution.
  • Bundling up to 400 independent questions improves reuse of shared evidence but does not support dependent decision chains in one request.
  • Low per-token pricing excludes evaluation creation, monitoring, human review, retries, integration, and the business cost of false decisions.
  • A dedicated service in the action path adds availability, timeout, rate-limit, and regional-capacity dependencies.
  • Typed answers reduce parsing ambiguity but do not prove that the question, choices, rubric, or supplied evidence encode the right policy.
  • Zero Data Retention, regional processing, and other controls have eligibility and configuration requirements that teams must verify for their own account and endpoint usage.
  • Pricing, supported models, and service behavior may change after general availability.
08 / Editorial analysis

The AI Signal take

The signal is not another cheaper model. It is the split between thinking and deciding. A large reasoning step can prepare context; a smaller typed call can choose the next branch. That is cleaner agent architecture—provided the team treats every probability as something to calibrate, monitor, and sometimes refuse to act on.
