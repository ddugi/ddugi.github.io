Publication policy

Privacy notice

Effective 14 October 2026. Dugi Selmanaj operates this publication and is responsible for its editorial content.

Information handled by this site

The site is static. It does not provide accounts or forms and does not use advertising trackers, browser storage, external fonts, or a subscriber database. Search and filtering occur locally in the browser and are not sent to the publication owner.

Audience measurement

Cloudflare Web Analytics is enabled. It measures aggregate page views, approximate unique visits, referrers, countries, browsers, devices, and page performance so the editor can understand whether the publication is being read.

AI Signal does not use analytics cookies, create visitor profiles, or expose a list of visitor IP addresses to the editor. Cloudflare receives technical request data to provide the measurement service under its own privacy commitments. Aggregate counts are approximate and should not be treated as a list of identified people.

Hosting and external links

GitHub Pages hosts the site and may process normal technical request information such as IP address, requested URL, timestamp, and user agent under GitHub’s own terms and privacy practices. Following an external link sends a request to that destination, which applies its own privacy policy.

Contact and public issues

Questions can be raised through the maintainer’s public GitHub profile. Do not place confidential information, vulnerability details, or unnecessary personal data in a public repository issue. Security concerns follow the repository’s private reporting instructions.

Future changes

If subscriptions, forms, accounts, or materially different data collection are introduced, this notice will be updated before that processing begins. Material changes will receive a new effective date.

This concise notice reflects the current static publication and is not a substitute for jurisdiction-specific advice where future services process personal data.
