Privacy notice

Effective 18 September 2026. Dugi Selmanaj operates this publication and is responsible for its editorial content.

Information handled by this site

The site is static. It does not provide accounts or forms and does not intentionally use analytics, advertising trackers, cookies, browser storage, external fonts, or third-party JavaScript. Search and filtering occur locally in the browser and are not sent to the publication owner.

Hosting and external links

GitHub Pages hosts the site and may process normal technical request information such as IP address, requested URL, timestamp, and user agent under GitHub’s own terms and privacy practices. Following an external link sends a request to that destination, which applies its own privacy policy.

Contact and public issues

Questions can be raised through the maintainer’s public GitHub profile. Do not place confidential information, vulnerability details, or unnecessary personal data in a public repository issue. Security concerns follow the repository’s private reporting instructions.

Future changes

If subscriptions, analytics, forms, accounts, or other data collection are introduced, this notice will be updated before that processing begins. Material changes will receive a new effective date.

This concise notice reflects the current static demonstration site and is not a substitute for jurisdiction-specific advice where future services process personal data.
