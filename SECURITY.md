# Security policy

## Supported version

Only the version currently deployed from the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put visitors or maintainers at risk. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the repository owner through the contact method on their GitHub profile and request a private channel without including exploit details in the first message.

Include the affected URL or file, impact, reproduction steps, and suggested mitigation when possible. You should receive an acknowledgement within seven days. No bounty program is offered.

## Scope

The site is static and intentionally has no accounts, forms, database, analytics, secrets, payment handling, or server-side application. Reports about GitHub itself or GitHub Pages infrastructure should be sent to GitHub.
