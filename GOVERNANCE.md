# Governance and release controls

Dugi Selmanaj is the repository owner, code maintainer, and responsible editor. Repository access does not itself authorize publication.

## Required publication flow

1. Prepare a focused pull request.
2. Run the automated build and policy checks.
3. Review factual claims, sources, rights, privacy, and presentation.
4. Record human editorial approval in structured content for reported stories.
5. Merge only when required checks pass.
6. Verify the deployed page and links.

Emergency corrections may use an accelerated review, but must retain a clear commit message and be followed by normal verification. Roll back by reverting the responsible commit and confirming the Pages deployment.

The repository history is the primary change record. Published corrections also follow `ai-signal/policies/corrections/`.
